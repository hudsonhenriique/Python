# 🐍 Python Core: Automação, APIs e Dados

## 📌 Visão Técnica
Este repositório documenta a implementação de algoritmos em **Python 3**, evoluindo de scripts lógicos fundamentais para aplicações de **Engenharia de Dados** e **Integração de Sistemas**.

O diferencial deste portfólio é a aplicação prática de conceitos de manipulação de arquivos (I/O) e consumo de dados externos, simulando rotinas reais de um ambiente corporativo.

## 📂 Arquitetura do Repositório

### `01_Fundamentos_Logica`
Scripts focados na sintaxe core e controle de fluxo condicional.

### `02_Estruturas_Dados`
Manipulação avançada de estruturas em memória (**Listas, Dicionários, Tuplas**), essenciais para o tratamento de datasets antes da carga em bancos de dados.

### `03_Modularizacao_Funcoes`
Implementação de Clean Code através do encapsulamento de regras de negócio em funções e criação de módulos personalizados (`modulos_lib`).

### `04_Ingestao_Manipulacao_Arquivos`
**Destaque:** Rotinas de leitura e escrita de dados persistentes.
* Processamento de arquivos `.csv` e `.txt`.
* Scripts de automação para extração e carga de informações (ETL simples).

### `05_Integracao_APIs_JSON`
**Destaque:** Scripts de interação com fontes de dados externas.
* Consumo de APIs públicas (Ex: Consulta de CEP/Endereços e API de Games).
* Tratamento e *parsing* de objetos **JSON**.

### `06_Laboratorio_Algoritmos`
Coleção de exercícios práticos para refinamento de lógica e resolução de problemas.

### `07_App_Loteria`
Aplicação que simula regras de negócio complexas de um sistema de sorteios, integrando lógica matemática e estruturas de dados.

## 🚀 Como Executar
1. Clone o repositório.
2. Para scripts que manipulam arquivos (Pasta 04), certifique-se de que os arquivos `.csv` de origem estão no mesmo diretório.
3. Execute via terminal: `python nome_do_script.py`

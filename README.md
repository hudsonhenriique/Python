# 🚀 Jornada Python com Teo Calvo

Bem-vindo ao meu repositório de estudos de Python! Este espaço é dedicado a documentar minha evolução diária e registrar os exercícios e desafios propostos no curso de Python do [Teo Calvo](https://www.linkedin.com/in/teocalvo/).

O objetivo principal é construir um portfólio sólido de habilidades em Python, cobrindo desde a sintaxe básica até aplicações mais complexas, como análise de dados e automação.

## 🗂️ Estrutura do Repositório

O repositório está organizado de forma progressiva, acompanhando a estrutura do curso:

* **`/dia_01`** a **`/dia_09`**: Cada pasta `dia_` corresponde a um módulo ou dia de estudo. Elas contêm os scripts `.py` com os conceitos e exercícios aprendidos naquele tópico.

* **`/exercicios`**: Uma pasta para exercícios práticos variados ou listas de exercícios que consolidam o conhecimento de vários dias.

* **`/desafio`**: Contém um desafio mais complexo que integram múltiplos conceitos aprendidos ao longo do curso.

* **`.gitignore`**: Arquivo de configuração para garantir que arquivos desnecessários (como ambientes virtuais `.venv` ou arquivos de cache `__pycache__`) não sejam enviados para o repositório.
